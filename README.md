# DSA Tracker

A web app to keep tracks and solutions of the question in leetcode, for the users who would love to keep everything about their problems in one place .

## Tech
Next.js, TypeScript, Supabase (later)

## Pages
- `/` → dashboard 
- `/problems` → all problems' page
- `/problems/[id]` → each problem question
- `/problems/new` → every new problem
